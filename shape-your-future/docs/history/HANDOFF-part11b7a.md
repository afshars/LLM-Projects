Flags: `--all` (every finding; default shows 8 per check), `--strict` (warnings fail too). Exit 1 on any ERROR, else 0.
- It imports `DICTIONARIES` from `src/lib/dictionary.ts`, i.e. exactly what the app ships (app copy + `growth` + `ui`), and flattens it to dot paths (`a.b.c`, arrays `a.b[0]`).
- THIS PROJECT HAS NO `{name}` TOKENS: copy is written as functions `(count, shown) => ...`. So "placeholder" has two meanings:
  - plain string: set of `{name}` tokens must be equal in en and fa (supported; none exist today);
  - function: the script CALLS it with marker arguments. ERROR when the declared argument count differs, or when the set of arguments that reach the output differs. An argument is "used" if its marker is printed, or if changing it 7 -> 8 changes the output (so `Intl.NumberFormat(...).format(n)` in fa counts). An argument used only to pick singular/plural (`count === 1`) does NOT count: en may branch on it and fa may ignore it (the existing `planTodayHint` pattern).
- ERRORS: key in one language only (also string vs function, array length); empty / whitespace-only value, or a function that returns empty / throws / returns a non-string when probed; placeholder / argument mismatch.
- WARNING: fa identical to en (strings: trimmed equal; functions: same output for the same markers). Skipped when the text has no letters (numbers, units, symbols) or is in the allowlist (`ALLOW_SAME_VALUES` / `ALLOW_SAME_PATHS`, both empty today).
